# Intro to Programming: Living Textbook


Intro to Programming: Living Textbook is a language‑agnostic,
classroom‑tested introduction to core programming fundamentals. Designed
primarily for first‑time learners, the book blends clear conceptual
explanations, visual supports, and an instructional structure rooted in
Gagné's nine events of instruction to promote measurable learning gains.

This living online textbook is iteratively refined from real student
performance data and instructor feedback, so examples, pacing, and
emphasis evolve to improve comprehension and transfer. Rather than
prescribing fixed end‑of‑chapter labs or problem sets, the text
separates formative practice (provided by instructors) from the core
conceptual material, making it easy to integrate into diverse course
designs and assessment strategies.
